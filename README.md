# Sport Analyst

Автоматизированный проект для сбора спортивных данных, построения моделей, бэктестов и формирования ежедневных прогнозов.

## Текущий рабочий модуль: MLB

Пайплайн автоматически:
- загружает исторические результаты Retrosheet;
- получает ближайшее расписание MLB и заявленных стартовых питчеров;
- получает текущие ERA, WHIP, IP, K/9 и BB/9 стартовых питчеров;
- обновляет Elo-рейтинг команд;
- выполняет последовательный бэктест вероятностей без использования будущих матчей;
- запускает отдельный исторический betting-backtest при наличии архива коэффициентов;
- при наличии `ODDS_API_KEY` загружает текущие moneyline-коэффициенты;
- рассчитывает fair odds, no-vig market probability, edge, EV и размер ставки по 1/4 Kelly;
- ограничивает выдачу максимум тремя одиночными ставками в день;
- без коэффициентов или достаточного преимущества ставит статус `NO BET`.

## Исторический ROI-бэктест

Модуль `src/mlb_betting_backtest.py` ожидает файл:

`data/raw/mlb/mlb_historical_odds.csv`

Обязательные поля:
- `date`;
- `home_team`;
- `away_team`;
- `home_decimal_odds`;
- `away_decimal_odds`.

Необязательное поле: `bookmaker`. Пример схемы находится в `data/schemas/mlb_historical_odds_example.csv`.

При наличии нескольких букмекеров используется медианная предматчевая линия. Бэктест считает количество ставок, win rate, средний коэффициент, прибыль в юнитах, ROI и максимальную просадку. Если реального архива нет, система создаёт отчёт со статусом `blocked_missing_historical_odds` и не публикует выдуманный ROI.

## Пороговые фильтры
- минимальный edge: 3.5 процентного пункта;
- минимальный EV: 2.5%;
- максимум ставки: 1 юнит;
- размер ставки: 1/4 Kelly;
- максимум рекомендаций: 3 в день;
- при неполных данных по стартовым питчерам применяется штраф за неопределённость.

## Структура
- `src/` — загрузчики, модель и расчёт ставок;
- `data/` — исходные и обработанные данные;
- `models/` — рейтинги и обученные модели;
- `backtests/` — игровые прогнозы и исторические ставки;
- `reports/` — метрики качества, ROI и просадки;
- `predictions/` — ежедневные прогнозы;
- `.github/workflows/` — автоматические запуски.

## Запуск
```bash
pip install -r requirements.txt
python run_pipeline.py
```

## Текущие коэффициенты
Для расчёта edge и EV в GitHub необходимо добавить Actions secret с именем `ODDS_API_KEY`. Без него система продолжит работу, но не будет рекомендовать ставки.

## Ограничение текущей версии
Исторический betting-backtest использует Elo-вероятности. Поправка на стартовых питчеров пока применяется только к текущим матчам, потому что для честного исторического теста нужны данные о заявленных стартерах и их статистике именно на момент каждого матча.

Проект не гарантирует прибыль. Любые ставки связаны с риском потери средств.
