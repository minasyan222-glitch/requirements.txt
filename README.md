# Sport Analyst

Автоматизированный проект для сбора спортивных данных, построения моделей, бэктестов и формирования ежедневных прогнозов.

## Текущий рабочий модуль: MLB

Пайплайн автоматически:
- загружает исторические результаты Retrosheet;
- получает ближайшее расписание MLB и заявленных стартовых питчеров;
- получает текущие ERA, WHIP, IP, K/9 и BB/9 стартовых питчеров;
- обновляет Elo-рейтинг команд;
- выполняет последовательный бэктест базовой Elo-модели;
- при наличии `ODDS_API_KEY` загружает букмекерские moneyline-коэффициенты;
- рассчитывает fair odds, edge, EV и размер ставки по 1/4 Kelly;
- ограничивает выдачу максимум тремя одиночными ставками в день;
- без коэффициентов или достаточного преимущества ставит статус `NO BET`.

## Пороговые фильтры
- минимальный edge: 3.5 процентного пункта;
- минимальный EV: 2.5%;
- максимум ставки: 1 юнит;
- максимум рекомендаций: 3 в день;
- при неполных данных по стартовым питчерам применяется штраф за неопределённость.

## Структура
- `src/` — загрузчики, модель и расчёт ставок;
- `data/` — исходные и обработанные данные;
- `models/` — рейтинги и обученные модели;
- `backtests/` — прогнозы исторического теста;
- `reports/` — метрики качества;
- `predictions/` — ежедневные прогнозы;
- `.github/workflows/` — автоматические запуски.

## Запуск
```bash
pip install -r requirements.txt
python run_pipeline.py
```

## Коэффициенты
Для расчёта edge и EV в GitHub необходимо добавить Actions secret с именем `ODDS_API_KEY`. Без него система продолжит работу, но не будет рекомендовать ставки.

## Ограничение текущей версии
Метрики бэктеста пока относятся только к Elo-модели. Корректный исторический ROI с учётом стартовых питчеров и букмекерских цен потребует отдельного архива исторических коэффициентов и данных по стартерам на момент матча.

Проект не гарантирует прибыль. Любые ставки связаны с риском потери средств.
